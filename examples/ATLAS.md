# ATLAS.md - Instruções do Projeto

Este arquivo define diretrizes específicas para o **atlas-agent** quando operando neste repositório.

## Diretrizes Gerais
- Manter o código limpo, sem dependências externas.
- Escrever testes para qualquer nova ferramenta em `tests/`.
- Seguir o padrão de nomes PEP 8 para Python.

## Comandos de Teste
- Suíte completa: `python3 -m unittest discover -s tests -v`
